================================================================================
PARTITION ATTEMPT A — sport/dport DROP on lo (Step 3 old rules)
================================================================================

Rules: DROP tcp on lo with --sport 8001|8002 --dport 8003|8004|8005 (and reverse).

iptables -L INPUT: 12 DROP lines, ALL pkts=0 after cluster activity.

/status: all nodes same term (e.g. 4), one leader (e.g. node1), same commitIndex.

Conclusion: rules did not match Raft TCP (Go dials use ephemeral source ports, not
8001–8005). Cluster remained fully connected.

================================================================================
PARTITION B — 127.0.0.1 ↔ 127.0.0.2 DROP on lo (working split)
================================================================================

Rules:
  INPUT -i lo -s 127.0.0.1 -d 127.0.0.2 -p tcp -j DROP
  INPUT -i lo -s 127.0.0.2 -d 127.0.0.1 -p tcp -j DROP

iptables counters (representative):

  num  pkts  bytes  match
  1    840   60114  127.0.0.1 → 127.0.0.2  DROP
  2     12     624  127.0.0.2 → 127.0.0.1  DROP

Cross-IP loopback traffic blocked; pkts increased → partition active.

/status DURING partition (127.0.0.1:9001–9005):

  port  id    leader  term  commitIndex
  9001  node1 false   3     3
  9002  node2 false   3     3
  9003  node3 false   2     2
  9004  node4 true    3     4
  9005  node5 false   2     2

Interpretation:
  - Minority side (node1–2): term 3, commitIndex 3, no local leader.
  - Majority side: node4 leader term 3, commitIndex 4 after write below.
  - node3, node5 lagging (term 2, commitIndex 2) while node4 advanced — majority
    subgroup not fully synced in this snapshot (replication/election under split).

Writes during partition:

  curl 127.0.0.1:9004/write?key=maj&val=1  → ok   (majority leader)
  curl 127.0.0.1:9001/write?key=min&val=1  → fail (curl -sf; no ok body)

Minority did not accept a successful replicated write; leader on 9004 committed
entry advancing commitIndex 3 → 4 on node4 only (node1–2 stuck at 3).
